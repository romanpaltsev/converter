# CLAUDE.md — ключевые решения проекта

Черновик, дополняется по ходу работы. Полная версия (структура, как добавить инструмент) — в конце MVP.

## Ограничения
- Репозиторий публичный. Push в `main` запускает деплой на VDS — пушить только с разрешения владельца.
- `SPEC.md` (задание владельца) в git не коммитится (исключён через `.git/info/exclude`).
- Реальные фото владельца — только `tests/fixtures/private/` (в `.gitignore`).

## Конвейер (замеры прототипа, Chromium/WebKit/Firefox, десктоп)
- Декодер: libheif-js 1.23.5, вариант с отдельным `.wasm` (не wasm-bundle: −200 КБ gzip, потоковая
  компиляция, кэш). Вызываем сырой C API (`_heif_*`): обёртка libheif-js не отдаёт ICC/nclx/Exif.
  Сборка libheif синхронная (`WASM_ASYNC_COMPILATION=0`) → `instantiateWasm` обязан вернуть экземпляр синхронно.
- RGBA не копируется: view в памяти libheif, выравнивание строк убирается на месте.
- JPEG: MozJPEG через jSquash, **baseline** (`progressive: false`): вдвое быстрее, файл +~4 %.
- Память (heap WASM): 24 Мп — libheif 133 МБ + MozJPEG 547 МБ; 48 Мп — 269 + 1027 МБ.
  MozJPEG в jSquash ~20 байт/пиксель: RGBA копируется в кучу дважды (embind `std::string`)
  плюс полнокадровые буферы коэффициентов trellis (отключить через API jSquash нельзя).
  Уменьшить можно только своей сборкой MozJPEG с построчной подачей. Решение владельца (17.10.2026):
  оставляем jSquash, проверяем на реальном iPhone; если вкладка падает — своя сборка следующим этапом.
- Время: 24 Мп ≈ 2 с декодирование + 2,5 с JPEG; 48 Мп ≈ 4 + 6 с. PNG 24 Мп ≈ 48 МБ файл.
- Политика worker'а: файл > 30 Мп — в свежем worker'е и после него пересоздание; страховка — каждые 20 файлов;
  после фатальной ошибки — пересоздание и одна повторная попытка. На файлах одного размера heap не растёт.
- Результаты в Chromium, Firefox и WebKit побайтно совпадают.

## Метаданные
- Режим по умолчанию: только даты (DateTime, DateTimeOriginal, DateTimeDigitized, OffsetTime*,
  SubSecTimeOriginal) + Orientation = 1 + служебная ExifVersion.
- «Все метаданные»: весь EXIF и GPS, Orientation = 1, PixelX/YDimension = фактический размер;
  MakerNote только Apple (смещения относительные), остальные отбрасываются; IFD1 (миниатюра) — всегда нет;
  XMP не переносится. EXIF > 64 КБ в JPEG → сначала без MakerNote, затем только даты.
- Цвет: ICC исходника копируется; nclx → встраивается CC0-профиль (sRGB / Display P3 / Rec.2020);
  без colr → sRGB. PQ/HLG — предупреждение (тон-маппинга нет).

## Тексты
- Не обещать «файлы меньше за счёт MozJPEG»: при одинаковом числе качества MozJPEG даёт файл больше,
  чем libjpeg-turbo (но и качество выше). Решение владельца: нейтральная формулировка без обещаний.
- Без кликбейта и выдуманных цифр.

## Особенности окружения
- Vite 8: `worker.format: 'es'` обязателен; `new Worker(new URL(...), { type: 'module' })` — литералом.
- Предупреждения сборки «Module "fs"/"path"/"crypto" has been externalized» от libheif-js безвредны.
- headless Chromium не запускает 11-ю подряд загрузку через `<a download>` — в e2e не больше 10 скачиваний на контекст.
- WebKit в Playwright сообщает `blob:` URL как запросы — в проверке «нет сетевых запросов» их исключаем.
- Не используйте `pkill -f serve-dist` в той же команде, где упоминается это имя (убивает свою оболочку).
